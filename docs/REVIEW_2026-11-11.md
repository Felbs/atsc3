## atsc3 -- open (ordered by weight)

1. lab/m11_watch.py + m11_stream.py: one shed Baseband chunk (q_bb full, live only) desynchronises
   the ALP anchors for the rest of the run: bounds are absolute offsets that already counted the
   dropped bytes.  Fix: chunk-relative bounds, offset added at feed time.  Needs a gate that sheds.
2. `fe.reacquire()` is called on the decode thread while the front thread is inside
   push/_stream/frames: an old-tape cursor can overwrite the reset (nothing until TAPE_MAX forces
   another re-acquire), or the in-flight block lands on the new tape.  Fix: the decode thread sets
   an Event, the front thread re-acquires itself.  Needs a weak-signal capture to prove.
3. m9_fast cell_pool_fast(_sm): strided FFT view with no length check; a multiplex whose Subframe 0
   is longer than RF33's reads past the window.  Latent on the carriers in use.
4. m11_stream `_acquire`: a mis-decoded bootstrap symbol raises and ends the run instead of counting
   as a miss (plausible, weak signal).
5. m11_watch run(): the radio is closed under the reader thread and closed again in main()
   (plausible; driver-dependent; untested without the radio, so not touched).
6. Direct-player path only: prebuffer accounting uses 90 kHz where the segment's tick rate is meant;
   held segments not counted; every asset pushed into a video-only player stream.
7. Shutdown joins threads for 8 s where their drains allow 15-30 s, then closes their files.
8. LDM: a sample-continuity BREAK re-acquires without `pipe.reset()`.
9. tools/atsc3_audio.py:776: frames pending at a lane roll are decoded as the new lane (late by
   leftover x 33 ms for that generation).  tools/atsc3_tv.py: with `--lang spa` the audio language
   tags are the wrong way round.  Extra-argument strings are split on spaces (a path with a space).
10. tools/atsc3_watch_omarchy.sh takes an RF argument but waits for RF33's pids (13/14) with no
    timeout.
11. `restarts` in atsc3_run.py is a lifetime budget (30), not a rate.

## atsc3 -- tidy-ups not done

Old-ABI branches of the layered LDPC loader (3-6) only ever serve a stale binary and degrade
silently: require ABI 7.  Superseded kernels `ldpc_layered_q8` (E130) and `ldpc_layered_pack_f32`
(E118) with their gates: ~370 lines of C.  `cellpool_div_scatter_f64` has no caller.  The seven
`build_*_kernel.py` files and the ctypes loaders repeat one pattern.  m3_ldpc.py writes the float32
pass three times.  `--transport route` in atsc3_tv.py is half-wired (atsc3_tv_route.py is the
working one).  Unused: atsc3_audio `FRAME_SECONDS`, `_EX`, `lane_shortfall`; atsc3_tv
`Session.t_base`, `slot0`, PipeFeed `err/last_ok/written`; atsc3_quality `tail_bytes`, `import wave`;
m11_watch `import m6_cells`, `LiveWriter keep_mb`; m11_stream `Transport.init_pid`.  Help text of
`--ldm-procs`, `--decode-procs`, `--live-dir` no longer matches the code.  The v1 mux path is a
documented fallback: the owner's call.

Clean: every ctypes argtypes/restype against its C prototype; the E136 packed int16 path (no
overflow, lanes consistent); all C files under -Wall -Wextra; LeadGovernor, RespawnGuard, ClockTrim,
TsStitch arithmetic; the lane/idx tailing; the atsc3/ package.

## STVT -- fixed (tools/stvt_play_hd.sh, tools/stvt_run.sh, bootstrap.sh)

* The player supervisor exited without stopping its own setsid'd tail|ffmpeg|mpv pipeline (the
  "soak stop leaves the player" symptom), and the pipeline inherited the lock fd so no new
  supervisor could start.  Now: EXIT/INT/TERM trap, fd 9 closed for the pipeline and every sleep.
* kill_player killed every mpv and ffmpeg of the user (a recording included): now the pipeline's own
  process group; the liveness test is the same group's mpv.
* MAX_RESTARTS was a lifetime budget (rotation relaunches spend it in ~3 days): cleared after 3 min
  of a moving picture.
* stvt_run.sh started a new chain when stop_chain had failed (radio still held): now waits.
* `~/.stvt_autocal.env` overrode inline settings (antenna, SPS) and was skipped whole when STVT_IFGR
  was set: now always read, inline settings win one by one; STVT_RS/VITERBI/EQ honour the caller.
* pkill/renice patterns anchored; bootstrap.sh no longer reports a failed SoapySDRPlay3 build as done.

Tested with a stand-in pipeline (group kill, lock not inherited, trap on TERM, second supervisor
accepted).  NOT yet run with the radio: live test before any push.

## STVT -- open

Python/shell:
1. tools/tv_live.py: signal handlers are installed after the flowgraph is built; started with `&`
   it inherits SIGINT ignored, so for up to ~75 s of SDR-busy retries a stop request does nothing.
2. tv_live.py retune: gain writes are never read back and the ack says ok when a write failed;
   the non-SDRplay fallback passes IFGR as dB of gain.  The current antenna is not remembered
   (same-channel test, tap-cache key).
3. stvt_run.sh adopts a running chain/player without checking RF, program or gains.
4. tools/tv_replay.py is not the byte-faithful copy it says: its TEIScrub differs, STVT_RXF_FUSED
   and the sync alpha default are not applied, .cs16 duration is doubled, the diag dir is a
   hard-coded home path.
5. STVT_SKIP_RESAMP=1 cannot work (nothing reads STVT_NATIVE_RATE).  tv_player.py headless mode
   buffers 240 frames (~1.5 GB).  The dark-screen stall has no handling in stvt_play_hd.sh.

C++ (gr-atscplus; the default chain is EQ=long, RS=stock, VITERBI=hard, so 1-5 are opt-in paths):
1. atsc_rs_decoder_erasure: the miscorrection guards test byte 0 for 0x47 and bytes 1-3 as a clear
   TS header, but the sync byte is not in the codeword and the bytes are still randomized.  Measured
   on the installed block: 0 of 400 rescues accepted, 143 of 400 with byte 0 forced.  `STVT_RS=erasure`
   therefore decodes what stock RS decodes.  Also `max_erasures=0` becomes 1.
2. atsc_fpll_tight, fold mode: the real output is 62 samples later than the imaginary one
   (measured); with BLOCK_NCO the imaginary output is never written (measured: all zeros).  Both
   only matter to the widely-linear equalizer (`STVT_EQ=wl`).
3. atsc_wl_frontend still has the sync integrator at 0.40 (4ad7484 changed sync_soft only).
4. atsc_noise_blanker (STVT_NB=1) and the equalizer's impulse guard can latch for good after a
   level step.
5. RS erasure: `int` counters overflow after ~46 h of decoding; histogram decay tied to work() size.
   viterbi_soft: function-static `confs`/`last_field_pos` shared by two instances (tv_dual);
   SOVA confidence one dibit late.
6. fpll block mode: block edges depend on noutput_items (the "not reproducible run to run").
7. Small: deinterleaver emits each metric tag twice; tap cache `remove` then `rename`;
   equalizer_long `data()` returns 831 of 832.
These need a rebuild, an install (sudo) and an on-air A/B: not done in this session.

Tidy-ups: five sync variants instantiated nowhere (fieldlock, kalman, pathA, slidefs, tunable:
2,739 lines); atsc_wl_frontend is a hand copy of sync_soft + fs_checker; equalizer_long keeps
per-instance state in function statics and reads the tap cache in three places; dead headers
(atsc_basic_trellis_encoder.h, duplicate interleaver_fifo.h); tools/: manual_play.sh, tail_mpv.sh,
playback_monitor.sh, auto_recover.sh, chain_cycler.sh, mpv_watchdog.sh, skip_resamp_test.sh are
May one-offs nothing runs; tv_live.py: unused `socket`/`network` imports, a docstring that still
advertises the removed TCP sink, `_rs_is_2port` true on both branches.
